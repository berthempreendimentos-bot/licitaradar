
# Regra de Web Scraping
- **OBRIGATÓRIO**: O usuário exige que NUNCA seja utilizado Puppeteer, Selenium, Playwright ou navegadores em modo 'headless' nativo. Todo o fluxo de scraping de páginas DEVE ser feito exclusivamente pelo script Python ('coletar_mensagens.py') que utiliza 'pyautogui' e 'subprocess' para abrir o Chrome de forma 100% legível e visual para o usuário. Essa é uma restrição estrita.
